# Chat Web App

## Tech Stack

- Vite
- Typescript
- React 19
- Tailwind CSS
- shadcn/ui
- TanStack Query
- Zustand
- react hook form
- zod
- centrifuge-js

## Commands

```bash
pnpm install        # Install dependencies
pnpm run dev        # Dev server at http://localhost:5173
pnpm run build      # Type-check and build for production
pnpm run lint       # Run ESLint
```
